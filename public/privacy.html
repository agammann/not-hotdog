Privacy

not hotdog is published by Alexander Gregory Ammann (agammann).

Website and browser extension

Device-mode classification runs on your device with a bundled MobileNet model. Device-mode and extension images and verdicts are not uploaded to an inference service. No API key, account, or payment is required for that local workflow. The application has no advertising or analytics SDK.

The website downloads application and model files from its host. The host receives normal network information needed to serve files, including your IP address and request metadata, and may process operational and security logs under its own policies. This is distinct from uploading your image. Hosting is provided through OpenAI Sites; see OpenAI's privacy policy.

The extension is enabled per tab. For a protected image it may create a temporary local tab capture and crop it to the fully visible image. The capture is never uploaded or passed to page scripts. Only the cropped pixels are classified locally. Page text, browsing history, cookies, images, and verdicts are not sent by the extension.

Verdicts remain in memory for the current page. Reload or Clear results removes them. Model files may remain in the browser's ordinary cache or extension installation. Browser settings can clear cached site data. Pause or Escape stops new checks; a calculation already running may finish. Removing the extension removes its installed model files.

Optional hosted website checks

Hosted mode is a separate, manual second opinion using GPT-5.4 and your own OpenAI API key. Selecting a file or hovering does not send it. Pressing Send selected image sends one image, resized locally to at most 768 pixels per side and re-encoded as JPEG to remove file metadata. That image and your API key pass through this site's server to the fixed OpenAI Responses API. The application does not persist images, credentials, or hosted verdicts on the server or write them to application logs.

The key is held only in the current page, never localStorage, sessionStorage, or IndexedDB. Clear results & key, switching to device mode, leaving the page, or reloading clears it. Cancellation stops waiting for a result, but OpenAI may still process and bill a request already sent. Your OpenAI API account pays for hosted checks; ChatGPT subscriptions do not include API usage.

Requests use store: false. This is not a promise of zero provider retention: OpenAI's API data controls and retention policies apply. Hosting may process operational and security metadata under its policies. Share only images you are comfortable sending through these services.

ChatGPT and Codex plugin

The plugin uses the host assistant's existing image capabilities. Images you share in chat are handled by ChatGPT or Codex according to your account settings and the host's policies. This is not on device inference. The plugin does not transmit images to a publisher operated API or request your API credentials.
